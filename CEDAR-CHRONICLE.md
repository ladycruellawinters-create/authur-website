# Cedar Hollow Chronicle

`cedar-chronicle.html` is a fictional monthly town newspaper edited in-world by Elias Mercer. Issue 01 is October 2026, with six original website stories. The front page links to full articles inside the same page, with return links. All reading works without JavaScript. Entry links appear in homepage Reader extras, Cedar Hollow local favourites and the community board.

The author authorised first-of-month releases. Seven monthly authored editions are stored in `data/cedar-chronicle-issues.json`: the original October 2026 edition plus six new issues for November 2026 through April 2027, each with six stories. `chronicle-calendar.js` exposes only editions whose release day has begun in Europe/London (the first for monthly issues; the full date for specials); `cedar-chronicle.js` renders the newest available issue, updates each minute and on return to the tab, and offers an archive selector. Stable archive links use `cedar-chronicle.html?issue=YYYY-MM` for monthly editions and `?issue=YYYY-MM-DD` for dated specials. Invalid or unreleased issue requests fall back to the latest published issue. Browser back/forward works. The April monthly issue remains latest until the approved June special editions release. No May or June monthly issues have been authored by this change. More editions require writing and deploying another batch; there is no autonomous writing service or perpetual content generation.

Future issues in JSON are publicly accessible source, not confidential drafts. Keep actual spoilers outside this repository. The static October issue remains available without JavaScript and if the archive fails to load, with a clear status message; loading current issues and archive selection require JavaScript. No real-world scheduled job or email is required: eligible editions become visible when a reader opens the page or its clock refreshes. Release time is 00:00 UK on the first, including BST changes.

The newspaper follows the same private cast reference, seasonal calendar and release-stage restrictions as the community board. Keep supernatural identities, private romances and family truths out of issues; book incidents require explicit author approval. Avoid unconfirmed festival dates. The launch edition keeps Agnes and Oliver’s release storyline out entirely. Do not copy private cast notes or manuscript passages into the public source. Felix’s station is fictional; there is no radio stream or real station affiliation. No real subscriptions, advertisements, events or purchases are implied.

When preparing an edition, check every headline-to-article anchor, mobile reading width, plain-text spoiler boundaries and no-JavaScript reading. Use the UK calendar for issue dates. The October newspaper is an extra publication; existing community-board notices are unchanged.

Run `node --test tests/chronicle-calendar.test.cjs` for month/year/DST boundaries, queue completeness and unique titles. Browser checks cover scheduled release, future-link fallback, archive navigation/history, midnight refresh, fetch failure and mobile width. The prepared six-issue batch includes no release-story events and assumes no publication date. Recheck or replace any queued story if new book canon or author guidance changes before it is displayed.
